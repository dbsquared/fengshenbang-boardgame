# 封神榜 · 地牢（第一章网页原型）

《封神榜》桌游**第一章·地牢**的纯前端网页原型。水墨风格、六边格地牢、4 阶段回合制，目标是护送 **姬昌** 从牢房走回右侧的「卒」格。零依赖、零构建——双击即玩。

> ⚠️ 这是粉丝向的非官方原型，用于验证规则与玩法手感，并非商业发行版本。

## 在线试玩

**https://dbsquared.github.io/fengshenbang-boardgame/**

## 本地运行

- **最简单**：直接双击 `index.html` 用浏览器打开即可。
- **或起一个本地服务器**（推荐，避免个别浏览器对 `file://` 的限制）：

  ```bash
  cd fengshenbang-boardgame
  python3 -m http.server 8000
  # 浏览器打开 http://localhost:8000
  ```

## 玩法

- 你操控 **石友**，从右侧 4 个「卒」格之一出发，在六边格地牢中移动。
- 回合分 **4 个阶段**：`移动 → 出招 → 交互 → 敌方行动`。
- 出招阶段选招式卡（突刺 / 上挑 / 射击），再点敌人出招；内力耗尽或无可出招式时点「结束本阶段」。
- 走到姬昌（左下角牢房）相邻格子会触发剧情，进入**交互阶段**可「护送姬昌」让他跟随你回卒格；也可在交互阶段召**通灵猫**（移动 2 格 / 扑击 1 伤）。
- 把姬昌送回任意「卒」格即**胜利**；石友生命归零则**失败**。

## 敌方规则（依据说明书）

- 敌方每回合只翻 **行动牌库顶 1 张** 结算（步兵 4 张：突刺×3 + 上挑×1；弓兵 3 张：射击×3），7 张抽完洗回。
- 小兵被击败后在**离玩家最近的「卒」格**复活。
- 姬昌与玩家同时进入敌方射程时，敌方**优先攻击姬昌**。

## 原型辅助开关（偏离原规则，可取消）

原版为 4 人局，单人下「无限复活 + 姬昌 1 血 + 敌方优先打姬昌」几乎无法通关，故默认开启以下配平（取消勾选即回到说明书原规则）：

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 小兵复活上限 1 次／只 | 开 | 原规则：无限复活 |
| 姬昌 12 血、每回合走 2 格 | 开 | 原规则：1 血／1 格 |
| 内力 4 | 开 | 原 1，补偿 4 人份输出 |
| 小兵 2 只 | 开 | 原 4 只 |
| 演练模式（清空小兵） | 关 | 只验证护送与胜利判定链 |

## 技术说明

- 纯 HTML5 + 原生 JS + SVG，无框架、无构建步骤。
- 六边格采用 **flat-top 奇数列偏移（odd-q）** 坐标系，底图经单应矩阵（homography）校正对齐。
- 已通过 Playwright 无头脚本验证：护送→胜利判定链、敌方单卡结算、姬昌优先受击、小兵最近卒格复活等规则。
