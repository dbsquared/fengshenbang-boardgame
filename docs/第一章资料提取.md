## 二、角色面板

### 2.1 面板属性项（从 `角色面板.jpg` 读取）
四个角色面板（陈玄、石友、毛颖、方絮）均包含以下属性：

| 属性 | 标识颜色 | 说明 |
|---|---|---|
| 武力 | 红色 | 影响武力类招式伤害 |
| 内力 | 绿色 | 招式内力消耗上限/内力池 |
| 灵力 | 蓝色 | 影响灵力类招式/法力相关 |
| 体力 | 橙色 | 影响生命值上限 |

面板上另有装备栏：武器、防具、宝物、灵兽，以及“手卡”区域与生命值/移动力记录区。

### 2.2 生命值与移动力计算公式（来自 `提示卡-正面.jpg`）
- **移动力**：初始默认为 **2**，部分装备效果会有加成。
- **生命值**：初始默认为 **8**，每有 1 点体力额外增加 **3** 点生命值。
  - 即：生命值 = 8 + 体力 × 3

> 各角色面板上的具体初始武力/内力/灵力/体力数值因照片分辨率限制**看不清**。

## 四、提示卡

### 4.1 玩家提示卡（1–3 章）

1. **移动阶段**：移动步数 ≤ 移动力。
2. **出招阶段**：
   - 内力消耗 ≤ 内力；
   - 不打牌就可以回收弃牌；
   - 消耗 1 点生命值窥视天机。
3. **交互阶段**：
   - 灵兽行动
   - 同伴行动
4. **敌方行动**：结算最上面或最前面的敌方行动卡。

### 4.2 图标释义（与 1–3 章共用一面）

| 图标 | 含义 |
|---|---|
| 2+（翅膀） | 移动力：初始默认为 2，部分装备效果会有加成。 |
| 8+（血滴） | 生命值：初始默认为 8，每有 1 体力额外增加 3 点生命值。 |
| 数字（如 2） | 数字代表该牌消耗的内力值。 |
| X | X 表示玩家面板上的内力属性值。 |
| 0 | 表示该牌为应对卡并不消耗内力，通常在被敌方攻击时打出。 |
| 交叉双剑 | 4 种装备类别，必须装备该类武器，才能使用此招式。 |

### 4.3 玩家提示卡（4–12 章）

1. **移动阶段**：
   - 移动步数 ≤ 移动力；
   - 未消耗的移动力转化为抽取法力。
2. **出招阶段**：
   - 内力消耗 ≤ 内力 + 法力补充；
   - 不打牌就可以回收弃牌；
   - 消耗 1 点生命值或 1 法力窥视天机。
3. **交互阶段**：
   - 灵兽行动
   - 同伴行动
4. **敌方行动**：结算最上面或最前面的敌方行动卡。

### 4.4 图标释义（与 4–12 章共用一面）

| 图标 | 含义 |
|---|---|
| 卒字圆形 | 地图上我方玩家角色的初始位置 |
| 友字圆形 | 地图上同伴的初始位置 |
| 粉色菱形 | 地图上敌方首领的初始位置 |
| 骷髅圆形 | 地图上敌方小兵的初始位置（与敌方行动牌名称、立牌底色一致） |
