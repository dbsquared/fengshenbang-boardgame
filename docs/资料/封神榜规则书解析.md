# 《封神榜》桌游规则书解析（开发依据）

> 来源：工作区 `说明书/` 目录下 28 张规则书照片，由子任务逐张通读整理。
> 用途：作为封神榜页游开发的规则依据与术语表。
> 说明：部分旋转/反光页已尽力辨认；细部数值以实物卡牌为准。

---

## 1. 游戏概述

| 项目 | 内容 |
|------|------|
| **游戏名称** | 封神榜 |
| **游戏类型** | 中国风合作战役桌面游戏（卡牌驱动 + 版图 + 角色模型） |
| **游戏主题** | 以封神演义为背景，玩家扮演少年英雄，历经 12 个章节闯关推图、击败妖魔与头目。 |
| **适合人数** | 1–4 人（支持单人模式） |
| **预计时长** | 随章节而异，完整战役约数小时至十数小时。 |
| **核心玩法** | 回合制合作：玩家依次执行「移动 → 出招 → 交互 → 敌方行动」四个阶段，完成章节目标即胜利。 |

## 3. 玩家设置 / 开局

### 3.1 战前准备（第一次游戏）

1. **选择角色**：每名玩家选择一名角色，拿取对应的玩家面板、灵器标记、角色模型、1 张玩家提示卡、该角色初始卡牌（在背包收纳盒中）。
2. **装备初始装备**：每名玩家将 3 张初始装备卡分别放到玩家面板的武器、防具、宝物栏上方，表示已穿戴。
3. **填写属性**：计算并记录四种属性：
   - **武力 / 内力 / 灵力 / 体力**：装备卡上对应颜色数值的总和。
   - **生命值** = 8 + 体力 × 3。
   - **移动力** = 2 + 装备效果提供的移动力加值。
4. **灵兽设置**：若角色装备卡会召唤灵兽，取出灵兽立牌、灵兽行动卡，按卡牌生命值放置生命标记。

### 3.2 章节设置

- 游戏共有 **12 个章节**，按 1→12 顺序依次游玩。
- 打开对应章节收纳盒，取出该章节地图、敌方介绍卡、敌方行动卡、剧情卡、敌方立牌、宝箱/通关奖励卡等。
- 将地图嵌入地图板并展开。
- 将敌方介绍卡、剧情卡正面向上一字排开放在地图左上角备用。
- 将敌方行动卡洗匀后正面向上一字排开组成敌方行动牌库。
- 按地图图标放置敌方小兵立牌、头目立牌、叹号标记、玩家起始位置等。
- 每名玩家将角色模型放在地图上的玩家起始位置（多个起始位置可自选，但不能同格）。

### 3.3 起始玩家

- 自主选择一名玩家率先开始。
- 之后以顺时针方向轮流进行玩家回合。

## 4. 回合流程

每个玩家回合必须依次经历以下四个阶段：

### 4.1 一、移动阶段

- 玩家只能在地图中的**实线格**上移动；无线格、虚线格通常不可移动（章节特殊说明除外）。
- 每次移动消耗 1 点移动力移动到相邻格，总移动格数不可超过当前移动力。
- 每个格子**仅能容纳 1 名角色**，不可移动到已有角色的格子上。
- 移动时可以**穿越我方角色**（其他玩家、灵兽、同伴），但不能穿越任何障碍物。
- 敌方角色与章节说明中标明的障碍格均视为障碍物，不可穿越。
- 移动力可保留，例如移动力 2 可选择只移动 1 格。

> **获得法力**（通关第三章后解锁）：移动阶段结束后，未消耗的移动力转化为等量法力，从盲抽袋中随机抽取对应数量法力圆片。

### 4.2 二、出招阶段

玩家可自由选择以下行动执行，不限顺序和次数，只要满足条件：

#### 4.2.1 打出招式卡

- 所有招式卡作为手牌，打出时通常消耗内力。
- 每回合打出的招式卡内力消耗总和不应超过玩家面板上的内力属性值。
- 招式卡上的数字/X/0 含义：
  - **数字**：固定内力消耗。
  - **X**：消耗等于当前内力属性值（例如内力为 1，则 X=1）。
  - **0**：应对卡，不消耗内力，通常在敌方攻击时打出。
- 打出的招式卡按**从上到下、从左到右**顺序依次执行效果。
- 执行后该招式卡放入弃牌堆，回到手牌前无法再次使用。

#### 4.2.2 休整

- 若玩家在出招阶段没有打出任何招式卡，则可将弃牌堆所有卡牌拿回手中，重新变为可使用状态。

#### 4.2.3 窥觑天机

- **窥觑天机-寿**：玩家可失去 1 点生命值进行窥觑天机。将敌方行动牌库最上方的卡牌依次向右铺开，直到面朝上的卡牌数量等于当前玩家人数；敌方行动时优先执行最右那张。
- **窥觑天机-法**（第三章后解锁）：也可消耗 1 个任意五行法力进行窥觑天机。

#### 4.2.4 焚法淬元

- 玩家将 1 种类型的**所有**法力放入玩家面板对应图标框内，获得 1 点额外内力。
- 该额外内力仅用于本回合打出招式时消耗，不改变面板内力属性。
- 每种法力每回合只能焚法淬元 1 次，一回合最多 5 次。
- 出招阶段结束时，玩家面板上所有已使用的法力放回盲抽袋。

#### 4.2.5 激活装备效果

- 若满足装备激活条件，可立即使用装备效果。
- 装备效果只要条件满足，可多次激活。
- 部分装备需要消耗对应五行法力。

### 4.3 三、交互阶段

交互阶段中每个行动只能执行一次，但不限顺序。

#### 4.3.1 灵兽行动

- 若玩家已召唤灵兽，则由该玩家控制灵兽进行 1 次行动。
- 按灵兽行动卡从上到下依次执行效果。
- 灵兽移动规则与玩家相同。
- 当灵兽已在场时，无法再次召唤；只有死亡后才能重新召唤。

#### 4.3.2 同伴行动

- 若该章节激活了同伴，由当前回合玩家控制同伴进行 1 次行动。
- 展示同伴介绍卡，组装立牌并设置生命值，将同伴行动卡全部摆开。
- 与灵兽行动卡一样，按从上到下顺序执行效果。

### 4.4 四、敌方行动

1. 激活敌方行动牌库最上方的卡牌，执行 1 次行动。
2. 敌方行动卡按**从上到下**顺序依次执行卡牌效果；右上角标明执行该效果的对应敌方角色。
3. 执行完后将该卡牌翻面，背面向上放入敌方弃牌区；若牌库用完，则将弃牌区洗混后重新组成牌库。

#### 敌方移动规则

- 若无特殊说明，敌方角色向距离最近的玩家、灵兽或同伴移动。
- 敌方角色可穿越所有敌方角色，但不能穿越我方角色、同伴、灵兽及障碍物。
- 敌方移动时会避开障碍物，绕道移动。
- 当玩家处于敌方角色下一动作的攻击范围内时，敌方停止移动。
- 多目标距离相同时，由玩家选择目标。
- 多名小兵共同行动时，按立牌底色 **红 → 黄 → 蓝 → 绿 → 紫** 的顺序依次执行。

## 5. 核心机制

### 5.1 内力与招式

- 内力属性决定每回合可打出招式卡的总内力消耗上限。
- 招式卡分武器招式，需装备对应类别武器才能使用。
- 武器类别包括：刀、剑、枪、拳等（见卡牌图标）。
- 应对卡（0 内力）通常在敌方攻击时打出，可抵消或反击。

### 5.2 战斗与伤害

- 卡牌效果中的「造成 X 伤害」会使目标减少对应生命值。
- 伤害不区分敌我，对范围内所有目标生效（但玩家招式不会以其他友方单位为目标）。
- 视野遮挡：玩家招式生效的最短路径内有障碍物遮挡时，无法对障碍物后方单位施展招式。

### 5.3 位移效果

| 动作 | 说明 |
|------|------|
| 移动 X 格 | 普通移动，遵循移动规则。 |
| 飞跃 X 格 | 沿直线越过角色/障碍物，落点不能有任何单位。 |
| 拉近 X 格 | 令目标向自身靠近，每次位移后距离必须更小；遇阻停止。 |
| 推远 X 格 | 令目标远离自身，每次位移后距离必须更大；遇阻停止。 |
| 旋转 X 格 | 令相邻目标围绕自身顺时针或逆时针移动 X 格，遇到单位停止。 |

### 5.4 法力机制（第三章后解锁）

- **获得法力**：
  - 移动阶段未消耗的移动力转化为法力。
  - 玩家或灵兽击败一名敌方小兵（非头目）可抽取 1 个法力。
  - 部分卡牌效果可获得法力。
  - 叹号标记「抽取法力」效果可抽取 2 个法力。
- **使用法力**：
  - 焚法淬元获得额外内力。
  - 激活装备效果。
  - 部分剧情/章节机制需要消耗特定法力组合。

### 5.5 状态效果

#### 眩晕

- 附加眩晕时，将眩晕标记放在目标立牌或模型头顶。
- 若目标已有眩晕标记，则此次眩晕无效。
- **玩家眩晕**：回合开始时跳过移动阶段与出招阶段，正常执行交互阶段与敌方阶段；完成后解除眩晕。
- **敌方眩晕**：被激活或被要求行动时，不执行行动，直接将卡牌放入弃牌区；完成后解除眩晕。
- **眩晕时受伤**：处于眩晕状态的角色受到伤害时无法使用应对牌，且受到的伤害 +1；受伤后立即解除眩晕。

#### 中毒

- 附加中毒时，拿取一个中毒标记，将数字 2 面朝上放在目标立牌或模型头顶。
- 处于中毒状态下的角色每次移动、飞跃、旋转或被旋转后（无论主动被动），都会减少 1 点生命值，并将中毒标记数字减 1。
- 中毒标记为 1 时，再受到 1 次中毒伤害后移除。
- 不发生位移就不会受到中毒伤害。

## 6. 卡牌 / 单位类型

### 6.1 玩家相关

| 类型 | 说明 |
|------|------|
| 角色 | 玩家操控的英雄，拥有模型、玩家面板、初始卡包。 |
| 装备卡 | 武器/防具/宝物，提供属性与特效，最多穿戴 3 件。 |
| 招式卡 | 玩家手牌，消耗内力打出，最多携带 10 张；不可重复。 |
| 灵兽 | 由装备卡召唤的辅助单位，有独立行动卡与生命值。 |

### 6.2 敌方单位

| 类型 | 说明 |
|------|------|
| 敌方小兵 | 普通敌人，生命为 0 时死亡并移出地图；部分章节会复活。 |
| 敌方头目 | 关底 BOSS，通常生命为 0 时游戏胜利；部分头目会触发剧情或阶段转换。 |
| 同伴 | 部分章节激活的友方 NPC，由当前玩家控制。 |

### 6.3 地图标记

- **叹号标记**：玩家触碰到时可选择移除并执行下方效果：
  - 宝箱奖励：抽取 1 张宝箱奖励卡加入手牌。
  - 剧情事件：激活对应剧情卡。
  - 治疗生命：立即治疗自己 4 点生命。
  - 抽取法力：立即从盲抽袋抽取 2 个法力。

## 7. 胜负条件

### 7.1 游戏胜利

- 满足当章节胜利条件即可胜利。
- 常见胜利条件：
  - 将敌方头目生命值归 0。
  - 完成特定剧情事件。
  - 保护目标 NPC 到达指定地点。
  - 击败特定敌人或完成所有剧情。
- 胜利后，将获得的宝箱奖励卡和该章节通关奖励卡一起放入背包收纳盒，供后续章节替换卡组使用。

### 7.2 游戏失败

- 当**所有玩家生命值都为 0** 时，游戏失败。
- 部分章节有额外失败条件（如关键 NPC 生命值为 0、特定敌人到达某位置等）。
- 游戏失败后，归还该局游戏中已经获得的所有宝箱奖励卡。

## 8. 死亡与复活

### 8.1 敌方死亡与复活

- **死亡**：敌方小兵生命为 0 时死亡，立牌移除出地图。
- **复活**：下次轮到该小兵行动时，若章节有复活说明，则小兵复活并重新进入游戏；若无说明，则不再参与游戏。

### 8.2 玩家死亡与复活

- **死亡**：玩家生命值为 0 时死亡。
- **死亡后**：
  - 弃置所有招式卡，但法力可以保留。
  - 玩家模型替换为对应的灵器标记，放在原位置。
  - 死亡的玩家回合跳过移动阶段与出招阶段，正常执行交互阶段与敌方阶段。
- **复活**：
  - 当其他玩家停留或经过该灵器标记上时，可选择扣除自己当前生命值 1/2（向下取整）注入灵器标记，并将其拿起交给对应死亡玩家。
  - 死亡玩家将生命值调整为对应数值，并将模型放到复活者最近的位置（多位置时任选）。
  - 复活成功，到该玩家回合时正常进行游戏。
  - 复活时立即将所有应对卡（带 0 的卡牌）拿回手中，其他招式卡仍放在弃牌堆。

### 8.3 灵兽死亡与召唤

- **死亡**：灵兽生命为 0 时死亡，移除生命标记与立牌，等待下次召唤。
- **召唤**：灵兽通过激活装备卡效果召唤；达成召唤条件后，将灵兽立牌放到对应距离的空格上，不可与其他单位同格，并按灵兽行动卡数值放置生命标记。

## 9. 特殊规则 / 例外

### 9.1 配置卡牌规则（战役继承）

- 每次通关后，玩家会获得新的装备卡与招式卡（通关奖励 + 宝箱奖励）。
- 玩家可选择其中部分卡牌与现有卡牌替换，自由配置下次游戏用的卡牌，放入角色卡包中。
- 替换完成后，剩余卡牌放入背包收纳盒。
- 战前准备环节可随时使用背包中的卡牌再次自由配置。
- 每名玩家最多穿戴 3 件装备，携带 10 张招式卡作为手牌。
- **每名玩家配置的卡牌中不能有重复的招式牌**。
- 角色的初始卡牌并不限定该角色专用，其他角色也可以使用；未选择角色的初始卡进入背包，供所有玩家替换使用。

### 9.2 其他玩法模式

| 模式 | 调整 |
|------|------|
| **剧情模式** | 降低难度：头目生命调至 80%；开局每人盲抽 2 法力；可同时采用以上两点。 |
| **挑战模式** | 增加难度：开始关卡前将「暴怒」敌方行动卡加入敌方行动牌库并洗混。 |
| **单人模式** | 放置敌方行动牌时，卡牌背面向上而非正面向上；开始关卡前将「暴怒」卡加入牌库并洗混；其他规则不变。 |

### 9.3 各章节特殊机制摘要

| 章节 | 名称 | 关键特殊机制 |
